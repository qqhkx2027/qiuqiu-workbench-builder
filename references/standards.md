# 工作台搭建标准（8 铁律 + 模块库 + 移动端 + 国内习惯）

来源：48 个真实案例踩坑 + 本地实测。以下是非谈判条件，生成任何工作台都必须满足。

## 铁律 1 · 数据存储（localStorage）
- 所有数据保存在浏览器本地，刷新/关闭不丢失；单域名上限约 5MB，纯文本够用几百到几千条。
- 图片：上传时压缩到 800px 宽，最多 9 张，存 base64，避免外部链接。
- localStorage 的 key 统一前缀 `wb_{工作台标识}_` 避免冲突；多风格变体各自前缀（`wb_minimal_`/`wb_pink_`/`wb_dark_`）。

## 铁律 2 · 数据备份（必须有）
- 首屏提供「导出 JSON 备份」和「导入恢复」两个按钮（不要藏在设置里）。
- 导入支持上千条，不能有条数上限；清空数据需二次确认弹窗。
- 记账类额外提供「导出 CSV」。
- 数据累计到 30 条时，顶部温和提示「数据已积累 30 条，建议导出备份」。

## 铁律 3 · 全内联零外链（经验值千金）
- 单文件 HTML，所有 CSS/JS 内联；绝不引用任何外部框架、CDN、字体或图表库。
- 图表用手写内联 SVG（进度环、柱状图、饼图、折线图）。
- 导航图标用内联 SVG `<path>` 或项目内图片，**不要用 emoji 充当主要导航图标**；emoji 可以用于状态提示、空状态和正文标签。
- 字体用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`。
- 为什么：AI 生成的页面引用外部 JS → 用户只存了 HTML → 库 404 → 功能全废。

## 铁律 4 · 移动适配（高频场景在手机）
- 窄屏（<768px）自动单列堆叠；按钮最小点击区 44×44px（儿童向 ≥50px）。
- 输入框字号 ≥16px（否则 iOS 自动放大页面）。
- 表格在窄屏改卡片列表或允许横向滚动。
- 数字输入用 `type="number"` 唤起数字键盘。
- PC 侧栏导航 → 移动端底部 Tab / 汉堡菜单。
- 适配 iPhone 底部安全区：`padding-bottom: env(safe-area-inset-bottom)`。

## 铁律 5 · 「今天要处理」置顶
- 页面最上面放一块「今天要处理」：自动列出逾期未完成、今天该做、快到期的条目。
- 逾期项标红，每条给一键处理按钮。
- **昨天没做完的自动滚到今天，不要凭空消失。**

## 铁律 6 · 预置示例数据
- 首次打开必须有 3–5 条示例（其中 ≥1 条逾期），让用户立刻看到效果。
- 提供「清空示例数据」按钮。
- 严禁首次打开是空白页。
- **迭代新增模块时，seed 必须「按 key 增量回填」，绝不能用「某个旧 key 为空」做全量闸门。** 正确写法：定义 `need(k)`（key 为 null / 空数组 / 空对象即补示例），每个模块的示例数据各自 `if(need(k)) DB.set(k, 示例)`。错误写法：`if(DB.get('todos').length===0){ /* 一次性写全部 */ }` —— 老用户（localStorage 已有旧数据）会跳过整块，新模块只被初始化成空数组，永远显示空白。已发生的真实事故：快手菜/架子鼓/投资热度图因老用户 `todos` 非空而空白，改增量回填后刷新即自动补齐，且旧字段（如「纳斯达克」→「娜指」）需做兼容迁移。
- **模板令牌（token）必须双花括号且与 build 正则严格一致；smoke test 必须跑所有变体 + 断言令牌已替换。** 已发生的真实事故：source 里误写 `const THEME='{THEME}'`（单花括号），build.js 只替换 `{{THEME}}`，令牌从未被替换 → `ICON_IMGS['{THEME}']` 为 undefined，`(ICON_IMGS[THEME]||ICON_IMGS['minimal'])` 静默回退到 emoji，粉/黑主题侧边栏全是 emoji 且部署两轮都没发现——因为旧 smoke test 只在 minimal 变体上跑，minimal 回退到自己恰好通过。修复：① source 统一 `{{THEME}}`；② build.js 对每个变体分别跑 smoke；③ 每个变体断言 `new RegExp("const THEME='"+theme+"'").test(script)`，替换失败立即报错退出。经验：**只在一个变体上做冒烟 = 只能证明「那个变体」正常**；涉及主题/前缀隔离的代码必须全变体验证。

## 铁律 7 · 需求过载控制
- 每个工作台最多 3–4 个模块，不能更多。
- 用户要 5+ 模块时，先做核心 3 个跑通，后续迭代追加；每次迭代只加 1 个模块。

## 铁律 8 · 国内习惯
- 记账/财务：支出红色、收入绿色（与欧美相反）。
- 货币统一 ¥。
- 日期格式：`YYYY-MM-DD` 或 `MM月DD日`。

## 五大人群 × 典型模块库

### 🎓 学生 / 备考党
刷题练习（计数+正确率+分科统计）· 错题本（标签+重做+掌握度）· 学习规划（计划表+打卡矩阵+倒计时）· 作文/口语（批改记录+素材）。

### 💼 职场人 / 打工人
任务管理（待办+优先级 P0/P1/P2+完成切换）· 周报日报（自动汇总+格式化文本）· 数据报表（卡片+趋势折线+分类饼图）· 会议纪要（日期+参会人+议题+结论+跟进）。

### 📱 自媒体 / 副业党
选题管理（灵感→写作中→已发布 看板+排期）· 素材库（链接+标签+评分）· AI 写作辅助（标题优化+框架草稿）· 数据复盘（各平台记录+增长折线+优化笔记）。

### 👶 宝妈 / 家长
启蒙学习（认字任务+象形字翻转+组词）· 游戏闯关（关卡进度+动画反馈）· 积分激励（得分+商城+兑换确认）· 成长记录（身高体重+里程碑）。
特殊：启用「家长/孩子」双模式 Tab，家长模式 4 位密码（首次设置存本地），儿童向字体放大、按钮 ≥50px、配色鲜艳。

### 🎮 生活玩家 / 泛用户
记账理财（收支+分类+月预算进度+饼图）· 习惯打卡（矩阵+连续天数+热力图）· 减脂健身（体重体脂折线+运动打卡+食谱）· 日程待办（今日/本周+优先级+完成率）。

## 按需加档（用户提出才做）
- **部署上线**：说「想在手机上用 / 想分享」→ 必须走部署拿链接（微信打不开本地 HTML）。部署后自己先验证一次；教用户「手机浏览器打开 → 分享 → 添加到主屏幕」。
- **家长/孩子模式**：同页双 Tab，家长密码防误触（非真加密，不宣称加密）。
- **图片存储**：压缩 800px、最多 9 张、base64。
- **隐私边界**：部署后链接公开可访问，但数据在用户浏览器本地（这点安全）；页面不预填真实隐私数据。

## 不做的事
- 不做「管理后台」：个人工作台用户即管理员，做同页设置抽屉即可。
- 不做浏览器通知/系统推送：靠「打开就看见」的置顶区域等价于提醒。
- 不做账号体系：靠导出导入迁移数据。
- 不做视频/大文件存储。

## 多主题与图标流水线（本 skill 默认 6 套）

### 主题 = 模板令牌 + 隔离前缀 + 独立图标集
每套风格由三样东西共同定义，缺一个都不行：
1. `{{THEME}}` 令牌值（如 `cinnamoroll`）→ 运行时 `const THEME='{{THEME}}'` 取值。
2. `{{PREFIX}}` 独立 localStorage 前缀（如 `wb_cinnamoroll_`）→ 风格间数据互不覆盖。
3. `ICON_IMGS['<theme>']` 图标集 + `body[data-theme="<theme>"]` CSS 渐变面板。

新增一套主题的标准动作：
- 在 `scripts/build.js` 的 `VARIANTS` 加一条 `{theme, prefix, title}`；
- 在 `source.html` 顶部加 `[data-theme="<theme>"]{...}`（sidebar/topbar/card 渐变 + 图标尺寸）；
- 在 `assets/icons/icons.js` 的 `ICON_IMGS` 加 `'<theme>':{home:..., ...}`（9 模块 + brand）；
- 重新跑 `generate_theme_icons.py`→`patch_icons.py`→`build.js`；旧版九宫格素材仍可使用 `generate_icons.py`。

### 图标生成与图片主题
默认 6 套：`minimal`（轻量文字/emoji 回退，旧版兼容） / `dark`（旧版库洛米） / `pink`（美乐蒂） / `cinnamoroll`（玉桂狗） / `popmart`（POP MART 糖果色） / `kuromi`（Kuromi 紫夜）。新工作台优先使用内联 SVG 或项目内图片作为主要导航图标。
- 原图要求：库洛米/美乐蒂是 3×3 九宫格（每格一个形象，部分格是相机/水印需跳过）；玉桂狗是 4×3 网格。裁切用**内容感知居中 + 去白底**，做成 120px 圆形透明 PNG，再 base64 写入 `icons.js`。
- POP MART 原图为 10 张单图：按文件名排序取前 9 张作为模块图标，第 10 张作为 brand；使用 `tools/generate_theme_icons.py popmart <原图目录> --brand-index 9` 居中裁切为 120px JPEG data URI，再写入 `icons.js`。原图不必提交到仓库，成品已内联优化图标。
- Kuromi 原图为 9 张单图：按文件名排序分别对应 9 个模块，第一张同时作为 brand；使用 `tools/generate_theme_icons.py kuromi <原图目录>` 居中裁切为 120px JPEG data URI，再写入 `icons.js`。
- 防沾边技巧：九宫格先用水平投影找两形象之间的白缝切成上下两半（`split_grid_smart`），再各自 `make_circle`（按非白像素 bbox 居中、pad≈1.15–1.35 保证人物完整、圆形遮罩）。
- `patch_icons.py` 会把 `icons.js` 注入 `source.html` 的 `ICON_IMGS`，并把 `renderNav` 改成：图标是 `data:` 开头就渲染 `<img class="nav-icon-img">`（圆形），否则按内联 SVG 或文本回退；同时追加 `body[data-theme=...]` 的渐变面板 CSS。
- **令牌双花括号铁律同样适用于此**：若 `const THEME` 没被替换，必须让构建立即失败；不能依赖主题回退来掩盖令牌错误。`build.js` 会检查 `{{THEME}}`、`{{PREFIX}}`、`{{TITLE}}` 是否全部替换，并对每个变体执行冒烟测试。
